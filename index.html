03 / JSON DATA FORMAT

Contoh struktur minimal yang diterima.

{
  "name": "MyAnimation",
  "keyframes": [
    {
      "name": "Keyframe",
      "time": 0,
      "poses": [
        {
          "name": "Torso",
          "cframe": [0,0,0,1,0,0,0,1,0,0,0,1],
          "children": []
        }
      ]
    }
  ]
}

CFrame wajib berupa 12 angka. Keyframe dan pose akan divalidasi sebelum file dibuat.
