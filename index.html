Masukkan satu atau banyak Animation ID, satu ID per baris.

ID saja tidak memuat keyframe. File JSON harus berisi data keyframe yang diekspor melalui workflow resmi/berizin.
Catatan format: Browser ini menyiapkan file model XML (.rbxmx) dari data keyframe JSON. Buka di Roblox Studio lalu simpan sebagai .rbxm. Tool ini tidak mengambil atau membypass aset privat hanya dari ID.
